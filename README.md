# Smart Expense Management

A visualization-first expense application built with Next.js App Router and PostgreSQL. The authenticated dashboard shows income/expense/balance summaries, an interactive category donut, monthly expense trends and recent transactions from the owner's database records. Transaction management supports create, view, edit, confirmed delete, filters and pagination with exact whole-MMK amounts. Receipt processing and group/settlement flows remain planned.

Start with [local setup and the manual verification checklist](docs/SETUP.md). Copy the placeholders in [.env.example](.env.example) into a local ignored environment file; keep real credentials private.
